# Setup Instructions

To add your own photos to the website, follow these steps:

1. Look inside this folder, you will see an `images` folder (or you can create one if it doesn't exist).
2. Add your 5 photos into the `images` folder and name them exactly as follows:
   - `memory1.jpg` (For the "Aapse Mila" section)
   - `memory2.jpg` (For the "Aapke Saath Chai" section)
   - `memory3.jpg` (For the "Late Night Conversations" section)
   - `memory4.jpg` (For the "Aapki Photos Dekhkar Khush Hona" section)
   - `memory5.jpg` (For the "Aur Bhi Bahut Kuch Hai" section)
   
*Note: If your images are `.png` or have different names, you'll need to open `index.html` and change the filenames inside the `<img src="images/...">` tags around line 125 to 165.*

3. **To Edit the Letter Message:**
   Open `script.js` and look around line 170 for `const message = ...`. You can change the text between the backticks (\`) to whatever you want! Use `\n\n` to create a new paragraph.

Enjoy the celebration! 🎉
